# Project Architecture

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Database:** Prisma (SQLite for local, implementation pending)
- **Validation:** Zod

## Folder Structure
- `src/app`: App Router pages and API routes.
- `src/features`: Feature-based modules (components, services, types).
- `src/components/ui`: Shared, dumb UI components.
- `src/lib`: Shared utilities and helpers.
- `docs`: Documentation and feature specifications.
